# E13 - Codificação (Codebook)

| ID | Nome do Código | Definição | Exemplo (Corpus) |
| :--- | :--- | :--- | :--- |
| COD-1 | Auditoria Epistemológica | Questionamento direto da validade científica e matemática da lógica imposta pelo agente gerador. | "qual é a lógica matemática do SHEAR?" |
| COD-2 | Modelação Visual (Dupla Codificação) | Pedido focado em alterar a representação visual (cor, simultaneidade) para alívio de carga na memória de trabalho. | "criar uma figura resultante de cor diferente pra cada" |
| PAT-1 | Subtração Pedagógica (Anti-Spoiler) | Remoção de affordances textuais ou rótulos para impedir que a solução conceptual seja lida antes de descoberta. | "Deixe apenas Parte 1, Parte 2..." |
| PAT-2 | Austeridade de Interface | Eliminação de elementos da interface de utilizador (rodapés, painéis) que causam distração ou ruído cognitivo irrelevante. | "- retire o rodapé" |
